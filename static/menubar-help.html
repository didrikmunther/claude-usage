Reading the dials

  • Solid arc: used so far
  • Faint arc: what you'll add before the reset
  • Empty arc: what you'll have left at the reset
  • Red: you'll run out before the reset
  • Needle: how fast you're using it now

The number is the time until that limit resets. Claude is the orange dial, Codex the blue one. Turn on Verbose to also see percent used, the rate per hour and what's left.
